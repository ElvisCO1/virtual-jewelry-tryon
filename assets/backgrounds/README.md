# Imágenes para fondos virtuales

Guarda aquí los fondos JPG o PNG que quieras usar en las pruebas.
`peakpx.jpg` es una copia de la imagen original ubicada en la raíz del proyecto.

En la interfaz pulsa **Seleccionar imagen…**, elige el archivo y activa
**Fondo virtual**. También puedes seleccionar una imagen de otra carpeta.
